## Objective
Falsify or refine the hypothesis that ordinary digital-closet users value portability/migration and under-used-item recovery enough to justify a dedicated product wedge.

This pack intentionally does **not** claim demand, product-market fit, willingness to pay, revenue, or rank promotion.

## Target user
- owns or manages roughly 50+ wardrobe items;
- has tried, uses, or seriously considered a digital closet;
- feels setup/migration/data-loss friction or has a meaningful pool of under-used clothing;
- is not primarily a professional reseller.

## Frozen propositions
A. MIGRATION — switch closet apps without starting over.
B. RECOVERY — identify under-used pieces and prepare keep/sell/donate decisions.
C. CONTROL — maintain a private portable wardrobe backup with no lock-in.
D. GENERIC_AI_CONTROL — generic AI stylist using the user’s closet.

## Critical competitor observations
- Alta reduces onboarding friction with photo/database/receipt inputs and auto-tagging.
- Stylebook supports multi-import, web clipping, AI background removal and iCloud backup.
- Indyx already combines closet cataloguing, styling and resale, and offers paid human archivist services.
- Whering supports multiple import paths but does not provide local user backup.
- Acloset states data export is not currently supported.
- Indyx provides CSV export only through a manual support request with a small fee.

Therefore the test is **not** “can we build another closet app?” It is “is user-controlled portability / migration / recovery a materially stronger reason to adopt or pay?”
